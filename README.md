# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a basic project designed to calculate the simple interest on a given principal amount using the interest rate and time period. It helps users understand how simple interest is calculated quickly and easily.

## Formula
**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal (P):** The initial amount of money.
- **Rate (R):** The annual rate of interest in percentage.
- **Time (T):** The time period in years.

## Features
- Calculates simple interest using the standard mathematical formula.
- Takes principal amount, rate of interest, and time as inputs.
- Displays the calculated simple interest.
- Easy to understand and suitable for beginners.

## Example
Suppose:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = **100**
